# MVP Scope

## Required

- SoftRF Legacy support
- GNU Radio based DSP pipeline
- Offline IQ capture decoding
- Realtime RTL-SDR support
- Track state management
- Automated testing
- Linux support

## Nice To Have

- GeoJSON output
- KML output
- Replay functionality
- Multiple output adapters
- Multiple SDR support

## Explicitly Out Of Scope

- Browser UI
- Dashboard UI
- Authentication
- User management
- Databases
- Cloud services
- Mobile applications
- Additional RF protocols
